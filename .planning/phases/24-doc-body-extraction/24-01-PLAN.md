    - `from __future__ import annotations`; `import structlog`; a `@dataclass` (or a

        `PDF_MIME = "application/pdf"`
        `DOCX_MIME = "application/vnd.openxmlformats-officedocument.wordprocessingml.document"`

    - `def chunk_text(text, *, chunk_size, overlap, max_chunks) -> list[str]`:

        strip and DROP empty/whitespace-only chunks (no empty embeds); return [] for empty input.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| uploaded bytes → parser | Attacker-controlled document bytes cross into pypdf / python-docx |
| extraction output → downstream | Extracted text/chunk list flows to Plan 02's embed+upsert |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-24-01 | Denial of Service | extract_document (crafted/malformed PDF/DOCX crashes or hangs) | mitigate | Per-surface extraction wrapped in try/except Exception → returns skipped=True(reason=parse_error), never raises. pypdf/python-docx are pure-Python (no shell-out, no external process). |
| T-24-02 | Denial of Service | resource exhaustion — 500-page PDF / large body | mitigate | Size cap (`max_file_bytes`) enforced BEFORE any parse; `max_total_chars` truncation before chunking; `max_chunks` bounds the chunk list. |
| T-24-03 | Denial of Service | zip-bomb DOCX (10MB compressed → GB of XML in lxml) | accept | Bounded by the 10MB compressed-input cap; the try/except fail-soft prevents a MemoryError/parse blow-up from propagating. Residual pathological expansion within 10MB accepted (documented) — python-docx does not stream; streaming rewrite is out of scope. |
| T-24-04 | Tampering | text/markdown decode of hostile bytes | mitigate | `decode("utf-8", errors="replace")` — no eval, no code path executes document content; markdown kept as inert text (D-24 discretion), never rendered here. |
| T-24-05 | Information disclosure | module reaching for global settings/team context | mitigate | doc_extract.py is PURE (no `app.config` import, no team_scope) — it cannot leak or cross scope; all caps arrive as explicit args. |
</threat_model>

<task type="auto">
  <name>Task 2: Firebase deploy</name>
  <files></files>
  <action>
Déployer le site sur Firebase Hosting.

Séquence de commandes depuis le répertoire marketing-site/ :

```bash
cd D:/VSC/xbrain/marketing-site

# Vérifier que Firebase CLI est installé
firebase --version
# Si absent : npm install -g firebase-tools

# Vérifier l'authentification Firebase
firebase login --no-localhost
# Si non authentifié, cela ouvrira une URL pour s'authentifier avec team@grooveos.app

# Vérifier que le projet est correct
firebase use xbrain-495115

# Créer le site xbrain-marketing si pas encore créé (à faire une seule fois)
firebase hosting:sites:list --project xbrain-495115
# Si "xbrain-marketing" n'apparaît pas dans la liste :
firebase hosting:sites:create xbrain-marketing --project xbrain-495115

# Déployer
firebase deploy --only hosting:marketing --project xbrain-495115
```

En cas de succès, Firebase CLI affiche :
```
✓  Deploy complete!

Project Console: https://console.firebase.google.com/project/xbrain-495115/overview
Hosting URL: https://xbrain-marketing.web.app
```

Capturer l'URL de déploiement et la logger dans le SUMMARY.

En cas d'erreur "site does not exist" : exécuter `firebase hosting:sites:create xbrain-marketing` puis réessayer le deploy.

En cas d'erreur d'auth : `firebase login --reauth` puis réessayer.

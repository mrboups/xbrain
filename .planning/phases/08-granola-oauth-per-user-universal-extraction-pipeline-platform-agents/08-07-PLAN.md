```javascript
  function renderWelcome() {
    const body = getBody();
    const title = el('h2', {}, `Welcome to "${selectedTeam?.display_name || 'your team'}"!`);
    const desc = el('p', { class: 'xb-desc' }, 'Your team is set up. You\'re ready to use xbrain.');
    const startBtn = el('button', { class: 'xb-btn xb-btn-primary' }, 'Get started →');
    startBtn.onclick = dismiss;

    // Phase 8 plan 08-07 — optional Granola connect step
    const granolaBtn = el('button', { class: 'xb-btn xb-btn-secondary' }, 'Connect Granola (optional)');
    granolaBtn.onclick = renderGranolaStep;

    setHtml(body, title, desc, startBtn, granolaBtn);
  }

  // Phase 8 plan 08-07 — D1 RESEARCH.md: per-user Granola key submission
  function renderGranolaStep() {
    const body = getBody();
    const title = el('h2', {}, 'Connect Granola');
    const desc = el('p', { class: 'xb-desc' },
      'Paste your personal Granola API key. We\'ll poll your meetings privately and feed them into your team\'s memory. ' +
      'You can disconnect anytime. Your key is encrypted at rest.');
    const stepLabel = el('p', { class: 'xb-step-indicator' }, 'STEP 4 OF 4 — OPTIONAL');
    const keyInput = el('input', {
      class: 'xb-input',
      type: 'password',
      placeholder: 'Granola API key (gnlk_...)',
      autocomplete: 'off',
    });
    const errorDiv = el('p', { class: 'xb-error', style: 'display:none' });

    const saveBtn = el('button', { class: 'xb-btn xb-btn-primary' }, 'Save & continue');
    const skipBtn = el('button', { class: 'xb-btn xb-btn-secondary' }, 'Skip for now');

    saveBtn.onclick = async () => {
      errorDiv.style.display = 'none';
      const apiKey = (keyInput.value || '').trim();
      if (apiKey.length < 8) {
        errorDiv.textContent = 'Please paste a valid Granola API key.';
        errorDiv.style.display = 'block';
        return;
      }
      saveBtn.disabled = true;
      skipBtn.disabled = true;
      // Pitfall 7 RESEARCH.md: refresh token just before submit (LibreChat token may have rotated).
      const freshToken = await getToken();
      if (!freshToken) {
        errorDiv.textContent = 'Authentication expired. Please refresh the page and try again.';
        errorDiv.style.display = 'block';
        saveBtn.disabled = false;
        skipBtn.disabled = false;
        return;
      }
      try {
        const r = await apiCall('POST', '/v1/me/granola-key', {
          api_key: apiKey,
          team_scope: selectedTeam?.slug || selectedTeam?.team_scope || '',
        }, freshToken);
        if (!r.ok) {
          const errBody = await r.json().catch(() => ({}));
          throw new Error(errBody.detail || `HTTP ${r.status}`);
        }
        dismiss();
      } catch (e) {
        errorDiv.textContent = `Could not save key: ${e.message || 'unknown error'}`;
        errorDiv.style.display = 'block';
        saveBtn.disabled = false;
        skipBtn.disabled = false;
      }
    };

    skipBtn.onclick = dismiss;

    setHtml(body, stepLabel, title, desc, keyInput, errorDiv, saveBtn, skipBtn);
  }
```

Notes implémentation :
- Le bouton "Get started →" reste primary — l'utilisateur a TOUJOURS la possibilité de sauter Granola sans aucun frottement (D1 explicite : "Connect Granola (optional)").
- L'input est `type=password` pour ne pas afficher la clé en clair pendant la saisie.
- `autocomplete=off` — le navigateur ne mémorise pas la clé.
- Validation min length 8 — aligne avec le min côté Pydantic `GranolaKeyBody.api_key min_length=8`.
- `freshToken` via `getToken()` JUSTE avant le submit (pas un cache) — Pitfall 7 RESEARCH.md.
- `selectedTeam?.slug || selectedTeam?.team_scope || ''` — fallback au cas où la shape de l'objet team change. Si tout est vide, le serveur retournera 422 (clé `team_scope` requise).
- Le label "STEP 4 OF 4 — OPTIONAL" rend explicite que c'est la dernière étape et qu'elle est skippable.
- Si l'API retourne erreur, on n'efface pas la clé tapée (l'utilisateur peut retry sans re-coller).

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → /api/xbrain/token | LibreChat session JWT (httpOnly cookie ou XHR Authorization) |
| Browser → memory-api /v1/me/granola-key | Bridge JWT (iss=librechat-onboarding, exp=5min) signed by BRIDGE_SHARED_SECRET |
| Browser DOM → memory in clear | api_key visible during typing (input type=password masque visuellement) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-07-01 | Information Disclosure | api_key in browser DOM | mitigate | type=password masque la value à l'écran. autocomplete=off — pas de cache navigateur. |
| T-08-07-02 | Tampering | Replay LibreChat session token | mitigate | Pitfall 7 — getToken() refresh JUST avant le submit. Le bridge JWT issued a exp=5min — fenêtre courte. |
| T-08-07-03 | Spoofing | Cross-user submission | mitigate | Le bridge JWT iss=librechat-onboarding contient le sub réel du LibreChat user (cf. xbrain-routes.js token endpoint). Pas de body field qui pourrait override l'identité. |
| T-08-07-04 | Information Disclosure | api_key in browser console.log | accept | Pas de console.log de la clé dans le code. Si l'utilisateur ouvre devtools et logge manuellement, c'est son own-goal. |
| T-08-07-05 | Repudiation | Connexion silencieuse | mitigate | POST /v1/me/granola-key écrit audit_log (`me.granola_key.upserted`) côté memory-api (plan 08-03). |
| T-08-07-06 | Denial of Service | XSS via api_key field | mitigate | Le contenu de api_key est envoyé en JSON body — pas inséré dans le DOM. errorDiv.textContent (pas innerHTML) — pas d'injection HTML possible via error message. |
| T-08-07-07 | Tampering | Bridge JWT secret leak via JS | accept | Le BRIDGE_SHARED_SECRET n'est JAMAIS dans le JS. Le JS ne fait que demander un bridge JWT à `/api/xbrain/token` — c'est le serveur LibreChat qui signe. |
</threat_model>

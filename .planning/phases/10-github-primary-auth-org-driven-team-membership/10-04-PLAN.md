# Plan 10-04 — app-site GitHub primary sign-in (Option B redirect)

## Goal

Add a primary "Sign in with GitHub" button + status banners to the static teams page
(`https://example.com/account/teams/`). On click, redirect the full page to GitHub's
OAuth authorization endpoint. On return (query params `?code=...&state=...`), POST to
`/v1/auth/github/signin`, store the returned `xbt_` in localStorage, clean the URL,
and load the authenticated UI. Google sign-in is retained as a secondary option.

Implements RESEARCH.md Q7 state machine: UNAUTHENTICATED → AUTHENTICATED_GITHUB_ONLY /
AUTHENTICATED_GOOGLE_ONLY / AUTHENTICATED_BOTH, with link CTAs surfaced per state.

## Entry Gate

1. `POST /v1/auth/github/signin` returns 400 on bogus code (proves endpoint deployed).
2. **Manual prereq (mrboups):** `https://example.com/account/teams/` is in the GitHub
   OAuth App's "Authorization callback URL" list for client_id `Ov23liVqXmHkS6JdYpcN`.
   Without this, GitHub returns `redirect_uri_mismatch` on every redirect.
3. Firebase Hosting deploys triggered via `firebase deploy --only hosting:app-site`
   from `app-site/` work as expected.

**Add the GitHub flow** — append (before the closing `})();` of the IIFE):

```javascript
  // ── GitHub OAuth (Option B full-page redirect) ──────────────────────────────

  function initiateGithubSignin() {
    // Generate a CSRF state token, store in sessionStorage, redirect to GitHub.
    const state = (
      Math.random().toString(36).slice(2) + Math.random().toString(36).slice(2)
    );
    sessionStorage.setItem(STORAGE_OAUTH_STATE, state);
    const u = new URL("https://github.com/login/oauth/authorize");
    u.searchParams.set("client_id", GITHUB_CLIENT_ID);
    u.searchParams.set("redirect_uri", GITHUB_REDIRECT_URI);
    u.searchParams.set("scope", GITHUB_OAUTH_SCOPES);
    u.searchParams.set("state", state);
    window.location.href = u.toString();
  }

  async function handleGithubCallback(code, state) {
    const expected = sessionStorage.getItem(STORAGE_OAUTH_STATE);
    // Always strip the params from the URL — never leave them in the bar.
    window.history.replaceState({}, "", "/account/teams/");
    sessionStorage.removeItem(STORAGE_OAUTH_STATE);

    if (!expected || state !== expected) {
      alert("Sign-in failed: state mismatch (possible CSRF). Try again.");
      showSignIn();
      return;
    }
    try {
      const r = await fetch(`${MEMORY_API_BASE}/v1/auth/github/signin`, {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({
          code,
          redirect_uri: GITHUB_REDIRECT_URI,
          state,
        }),
      });
      if (!r.ok) {
        const text = await r.text().catch(() => "");
        throw new Error(`signin failed: HTTP ${r.status} ${text.slice(0, 200)}`);
      }
      const { xbt_token, user } = await r.json();
      localStorage.setItem(STORAGE_TOKEN, xbt_token);
      if (user && user.email) {
        localStorage.setItem(STORAGE_EMAIL, user.email);
      }
      await loadAuthenticatedUI();
    } catch (e) {
      alert("GitHub sign-in failed: " + (e && e.message ? e.message : e));
      showSignIn();
    }
  }
```

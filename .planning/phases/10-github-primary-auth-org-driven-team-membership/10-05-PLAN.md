# Plan 10-05 — Chrome extension GitHub-primary sign-in + Settings block UI

## Goal

- Reorganize the popup connection card so GitHub is the primary (visually dominant)
  sign-in button and Google is secondary (GHA-07).
- Split the background script's existing `linkGithubFlow` into:
  - `signinGithubFlow()` — new, calls `POST /v1/auth/github/signin`, mints `xbt_`
    directly, stores it in `chrome.storage.local` **under the canonical keys
    `xbt_token`, `user_sub`, `api_token_id`** (matching the contract written by
    `onboarding.js`), refreshes context menus.
  - `linkGithubFlow()` — kept verbatim for already-Google-signed-in users adding
    GitHub.
- In `options.html` (extension Settings), per-team admin section: add Block button
  to each member row (or Unblock + "blocked" badge if `member.blocked_at` is set),
  plus a mini-form to pre-block a GitHub login.

Add a new function in `chrome-extension/background.js` below `linkGithubFlow`
(after line 143):

```javascript
/**
 * Phase 10 GHA-07 — sign in via GitHub directly, no Google required.
 *
 *   1. Launch GitHub OAuth → get authorization `code` (reuses getGithubAuthCode).
 *   2. POST {code, redirect_uri, state} to memory-api /v1/auth/github/signin.
 *   3. Receive xbt_token + user info, store in chrome.storage.local UNDER
 *      THE CANONICAL KEYS xbt_token / user_sub / api_token_id (matches
 *      onboarding.js + every reader in the extension).
 *   4. Force context-menu refresh so org-derived teams appear.
 *
 * Returns {ok: true, source_user_id, email, github_username} or {ok: false, error}.
 */
async function signinGithubFlow() {
  try {
    const { code, redirect_uri } = await getGithubAuthCode();
    // getGithubAuthCode generates its own state internally; we don't re-verify
    // here — chrome.identity.launchWebAuthFlow + the state check in
    // getGithubAuthCode covers CSRF for the extension context.
    // Re-derive a state string for the memory-api signin call (the server
    // requires non-empty state; it's logged for audit but not validated since
    // the extension is the trust boundary).
    const state =
      Math.random().toString(36).slice(2) + Math.random().toString(36).slice(2);
    const r = await fetch(`${MEMORY_API_BASE}/v1/auth/github/signin`, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ code, redirect_uri, state }),
    });
    if (!r.ok) {
      const body = await r.text().catch(() => "");
      return { ok: false, error: `signin failed: ${r.status} ${body.slice(0, 200)}` };
    }
    const { xbt_token, user } = await r.json();

    // === REVISION 1 B-1 fix — CANONICAL chrome.storage keys ===
    //
    // These EXACT key names are required by every reader in the extension.
    // DO NOT prefix with "xbrain_" or rename — see PLAN-CHECK.md B-1 and
    // grep "chrome.storage.local.get" in this directory to confirm:
    //   - background.js:884 reads xbt_token
    //   - background.js:653 reads xbt_token + user_sub
    //   - background.js:794 watches changes.xbt_token (WS reconnect trigger)
    //   - popup.js (5 sites), options.js, librechat_autofill.js all read xbt_token
    //   - onboarding.js writes {xbt_token, user_sub, api_token_id}
    //
    // user_sub semantics: the source_user_id of the user row
    // ("github:<login>" or "google:<sub>"). The bridge keys WS on this value.
    // The 10-02 contract addition surfaces user.source_user_id in the response;
    // we fall back to "github:" + github_username if the server is older.
    const user_sub =
      (user && user.source_user_id) ||
      (user && user.github_username ? `github:${user.github_username}` : null);
    const api_token_id = (user && user.api_token_id) || null;

    await chrome.storage.local.set({
      xbt_token: xbt_token,           // canonical — watched by background.js:794
      user_sub: user_sub,             // canonical — used for WS connection URL
      api_token_id: api_token_id,     // canonical — used for revoke flow
    });
    // Invalidate cached teams and refresh context menus.
    await chrome.storage.local.remove([TEAMS_CACHE_KEY, TEAMS_CACHE_TS_KEY]);
    refreshContextMenus();
    return {
      ok: true,
      source_user_id: user_sub,
      email: user && user.email,
      github_username: user && user.github_username,
    };
  } catch (e) {
    return { ok: false, error: String(e && e.message ? e.message : e) };
  }
}
```

async function loadOrgBlocks(team, listEl) {
  const r = await _xbtFetch("GET", `/v1/teams/${team.id}/org-blocks`);
  if (!r.ok) return;
  const blocks = await r.json();
  listEl.innerHTML = "";
  for (const b of blocks) {

    item.style.cssText = "display:flex;justify-content:space-between;align-items:center;padding:4px 0;font-size:12px;";

    rm.addEventListener("click", async () => {
      const dr = await _xbtFetch("DELETE", `/v1/teams/${team.id}/org-blocks/${encodeURIComponent(b.github_login)}`);

async function onOrgBlockSubmit(team, login, listEl) {

}

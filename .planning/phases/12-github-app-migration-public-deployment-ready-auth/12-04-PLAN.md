### Task 1 — Rewrite check_github_org_membership in app/auth.py

**File(s):** `apps/memory-api/app/auth.py`

**What:** Replace the existing `check_github_org_membership` function (currently lines 124-187 per the read in planning) with the new installation-token-backed version. The new function:

1. New signature:
   ```python
   from enum import Enum
   from sqlalchemy.ext.asyncio import AsyncSession

   class OrgMembershipResult(str, Enum):
       MEMBER = "member"
       NOT_MEMBER = "not_member"
       INSTALL_REQUIRED = "install_required"

   async def check_github_org_membership(
       session: AsyncSession,
       github_user_token: str,   # ghu_... user-to-server token (or legacy gho_ for LibreChat)
       org: str,
   ) -> dict:
       """Check if a GitHub user is a member of `org` using an installation token.

       Steps:
         1. Resolve the user's GitHub login + numeric id from the user token (GET /user).
         2. Look up the installation_id for `org` via the hybrid helper.
            - If None → INSTALL_REQUIRED. (User must install the App on the org.)
         3. Mint the installation token (cached).
         4. GET /orgs/{org}/members/{username} with the installation token.
            - 204 → MEMBER. 404 → NOT_MEMBER. else → NOT_MEMBER + log.

       Returns:
         {
           "login": str,
           "github_id": int,           # numeric GitHub user id (consumers in me_github.py rely on this)
           "email": str | None,
           "name": str | None,
           "is_org_member": bool,
           "install_required": bool,
           "result": OrgMembershipResult,
         }

       The cache key on the in-process membership cache becomes
       (github_user_token[:16], org) — preserve the Phase 5 5-minute TTL pattern.
       """
   ```

2. Implementation outline (full body):
   - Keep the in-process 5-min cache `_github_membership_cache` keyed by `(token[:16], org)`. Cache key composition unchanged.
   - On cache miss:
     - `httpx.get` `/user` with the user token (same as today) → get `username`, `github_id`, `email`, `name`.
     - `installation_token = await get_installation_token_for_org(session, org)`.
     - If `installation_token is None`:
       ```python
       result = {
           "login": username,
           "github_id": user_data["id"],
           "email": user_data.get("email"),
           "name": user_data.get("name"),
           "is_org_member": False,
           "install_required": True,
           "result": OrgMembershipResult.INSTALL_REQUIRED,
       }
       ```
       Cache it (short TTL — 60s — so the user retrying after install gets the new state quickly).
     - Else:
       ```python
       org_r = await client.get(
           f"https://api.github.com/orgs/{org}/members/{username}",
           headers={"Authorization": f"Bearer {installation_token}", **_GH_HEADERS},
       )
       is_member = org_r.status_code == 204
       ```
       (RESEARCH Pitfall 4 — keep "204 = member, anything else = not member" semantics.)

       **REVISION 2 (M-4 fix) — 401 retry on membership endpoint.** If the installation token was revoked between mint (12-03 cache) and use here, `/orgs/.../members/...` returns 401. Wrap the call in a single-retry path:
       ```python
       org_r = await client.get(<url>, headers={"Authorization": f"Bearer {installation_token}", **_GH_HEADERS})
       if org_r.status_code == 401:
           # Token revoked between mint and use (rare). Force-refresh once.
           log.warning("github_app.membership_check.401_retry", org=org, username=username)
           installation_token = await get_installation_token_for_org(session, org, force_refresh=True)
           if installation_token is not None:
               org_r = await client.get(<url>, headers={"Authorization": f"Bearer {installation_token}", **_GH_HEADERS})
       is_member = org_r.status_code == 204
       ```
       Note: `get_installation_token_for_org` does NOT currently accept `force_refresh` — Plan 12-03 only exposes it on `get_installation_token`. **Update needed:** Plan 12-03's `get_installation_token_for_org` signature gets an optional `force_refresh: bool = False` kwarg that proxies to `get_installation_token`. Implement this small extension as part of Task 1 here (add the kwarg directly to `github_installation.py`).
     - Build the result dict and cache with the full 5-min TTL.
   - Drop the `server_pat` argument entirely. The cache key changes to omit it.

3. Imports to add at top of `app/auth.py`:
   ```python
   from enum import Enum
   from sqlalchemy.ext.asyncio import AsyncSession
   from app.services.github_installation import get_installation_token_for_org
   ```

4. Add the `_GH_HEADERS` constant if it doesn't already exist at module scope (mirror the one in `auth_github.py`):
   ```python
   _GH_HEADERS = {
       "Accept": "application/vnd.github+json",
       "X-GitHub-Api-Version": "2022-11-28",
   }
   ```

5. Keep `_github_membership_cache` and `_GITHUB_CACHE_TTL = 300` — only adjust the cache TTL on `INSTALL_REQUIRED` results to 60s (so retries after install reach reality faster).

**Why:** GHAPP-04 (server-to-server piece). Eliminates the long-lived PAT — every credential in the membership-check path is now short-lived: the user token (8h, refreshes) and the installation token (1h, cached 55min, auto-refresh). The new return shape exposes `install_required` so callers (the OAuth signin route in Plan 12-06 + the deps.py guard) can hand the install URL back to the frontend. The added `github_id` field preserves the data shape me_github.py used to fetch separately (B-2 fix lets it skip the duplicate `/user` call).

   async def _resolve_github_username(user, session: AsyncSession) -> str | None:

       Uses an App JWT (not an installation token) because /user/{id} is a
       non-installation endpoint that only requires App-level auth.

       if user.github_username:
           return user.github_username

               headers={"Authorization": f"Bearer {app_jwt}", **_GH_HEADERS},
           )

               return None
           login = r.json().get("login")
           if login:
               user.github_username = login
               await session.flush()
               await session.commit()
           return login

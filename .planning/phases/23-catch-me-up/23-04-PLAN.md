<objective>
Add the client half of "Catch me up" to the Chrome extension popup: mark the
thread read on focus / scroll-to-bottom; poll `unread-summary` when a team opens
and show a dismissible, shadcn-Neutral "Catch me up" banner ONLY when the unread
count is at/above the server-returned threshold; on click, POST `catch-me-up`
and render the ephemeral summary streamed over the caller's own `user:<sub>`
Centrifugo channel (`catchup_stream_*` frames) — never auto-run, and don't
re-nag the same unread window once dismissed. Extend the popup selector-contract
test with the new ids so it stays green; all strings English.

Purpose: SC#4 (the affordance shows only when volume is meaningful, mark-read
fires on focus/scroll, the contract test stays green) plus the client rendering
of the SC#3 ephemeral summary.

Output: banner in popup.html, styling in popup.css, wiring in popup.js, extended
test_popup_contract.mjs.
</objective>

```

POST /v1/teams/{id}/catch-me-up    -> 202 {"status":"accepted"} | 200 {"status":"nothing_to_summarize"} | 403 | 429
```

subscribed — see subscribeUserChannel/handleUserPublication) as frames typed
`catchup_stream_start` / `catchup_stream_chunk` (has `delta`) / `catchup_stream_end`.

new `catchup_stream_*` types there.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| server stream -> DOM | The streamed summary is untrusted text; it must reach the DOM via textContent only, never innerHTML. |
| popup UI -> LLM spend | The client must never trigger the (paid) summary except on an explicit user click. |
| per-member cursor | The banner/cursor are the caller's own local UI; nothing exposes another member's read state. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-23-08 | Information disclosure / XSS | catchup_stream_chunk render | mitigate | Summary deltas append via `textContent`, never innerHTML — enforced by the contract test's existing XSS guard over popup.js. |
| T-23-03 | Denial of service / LLM-cost | catch-me-up trigger | mitigate | catch-me-up is called ONLY from the `#btn-catchup-run` click handler; the banner itself never runs it; below-threshold means no banner at all. |
| T-23-05 | Information disclosure / privacy | banner + cursor | accept | The banner reflects only the caller's own unread count; mark-read/unread-summary expose no other member's cursor (server-enforced in 23-02) — no read-receipt surface is added client-side. |
| T-23-10 | Tampering / re-nag | dismiss logic | mitigate | A dismissed `since` window is recorded and suppresses re-show until the window changes — the summary is not forced on the user. |
</threat_model>

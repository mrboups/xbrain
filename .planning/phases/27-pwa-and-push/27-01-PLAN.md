```js
export function createApi({ baseUrl, getToken }) {
  async function request(path, { method = "GET", body = null, headers = {} } = {}) {
    // Authorization: Bearer <await getToken()>; omitted when the token is null.
    // Content-Type: application/json only when body != null.
    // Non-ok -> throw new Error(`HTTP ${r.status}: ${text.slice(0, 200)}`)  <- SAME message
    //           shape popup.js already produces, so existing catch/alert paths are unchanged.
    // 204 / empty body -> return null (do NOT call r.json() on an empty body).
  }
  return {
    request,
    me:              () => request("/v1/me"),
    myTeams:         () => request("/v1/teams/my-teams"),
    centrifugoToken: () => request("/v1/me/centrifugo-token", { method: "POST" }),
    listMessages:    (teamId, { before = null, limit = 50 } = {}) => request(...),
    postMessage:     (teamId, body) => request(`/v1/teams/${teamId}/messages`, { method: "POST", body }),
    agentAliases:    (teamId) => request(`/v1/teams/${teamId}/agent-aliases`),
    markRead:        (teamId) => request(`/v1/teams/${teamId}/mark-read`, { method: "POST" }),
    unreadSummary:   (teamId) => request(`/v1/teams/${teamId}/unread-summary`),
  };
}
```
`listMessages` builds the query with `encodeURIComponent(before)` exactly as

## Trust Boundaries

| chat-core -> platform shim | chat-core is surface-agnostic; every capability (storage, tab-open, notification) crosses into a surface-owned implementation |
| generated copy -> deployed artefact | `app-site/app/chat_core/*` ships to a public origin; `chrome-extension/chat_core/*` ships in the extension package |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-27-01-01 | Tampering | app-site/app/chat_core copies | mitigate | Copies are byte-identical and versioned; `node scripts/sync-chat-core.mjs --check` (Task 2) plus `test_chat_core_sync.mjs` fail on any divergence, so an edit made only to a deployed copy cannot survive a commit |
| T-27-01-02 | Elevation of Privilege | platform_chrome.openUrl | mitigate | `openUrl` re-validates with `isSafeHttpUrl` before opening a tab, preserving the Phase-22 rule that a URL is re-checked at the point of action (popup.js:1534) |
| T-27-01-03 | Information Disclosure | api.js baseUrl | mitigate | No origin literal is permitted in api.js (grep-asserted); each surface injects its own base so the PWA copy cannot be repointed by editing shared code |
| T-27-01-04 | Spoofing | assertPlatform | mitigate | A shim missing a member throws a TypeError at import, so a partially-implemented platform cannot silently no-op a notification or a token read |
| T-27-01-05 | Denial of Service | api.request error path | accept | Same `HTTP <status>` throw shape popup.js already had; no retry loop is introduced, so no new amplification surface |
</threat_model>

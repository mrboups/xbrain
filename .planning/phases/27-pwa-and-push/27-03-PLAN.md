The docstring must explain the two decisions a later reader will question:
  - **Why UNIQUE on `endpoint` ALONE rather than `(user_id, endpoint)`.** A push
    endpoint is a mailbox for one browser instance, not for one account. On a shared
    device, a second person signing in and enabling notifications gets the SAME
    endpoint back from the browser. A `(user_id, endpoint)` key would leave the first
    person's row alive and keep delivering the new occupant's notifications to the
    old account. Unique-on-endpoint forces the subscribe path to TRANSFER ownership
    (`ON CONFLICT (endpoint) DO UPDATE SET user_id = EXCLUDED.user_id, ...`), which
    is what makes "a subscription is never readable by another user" true on a
    shared device rather than only on a private one.
  - **Why `ON DELETE CASCADE`.** A deleted account must not leave a live delivery
    channel behind.
  - Per-device is expressed by the row itself: one row per endpoint, N rows per user,
    so revoking one device silences exactly that device (D-27-05).
Include a symmetric `downgrade()` that drops the table.

`POST /v1/push/subscribe` (201). Ordering is load-bearing — every rejection returns
BEFORE the write, so a rejected request provably stores nothing:
  1. user principal -> 403
  2. `_is_safe_push_endpoint(body.endpoint)` -> 422
  3. `rate_limit.check_rate(settings.PUSH_SUBSCRIBE_RATE_LIMIT, "push-subscribe", user.source_user_id)` -> 429
  4. THEN `repo.upsert(...)` + `session.commit()` -> `{"status": "subscribed"}`

`_is_safe_push_endpoint(url)` is a local pure helper (unit-tested):
scheme must be exactly `https`; `username`/`password` must be empty; the hostname
must not be `localhost`, must not be an IP literal in a loopback / private / link-local
/ unique-local range (use `ipaddress` — reject `is_private or is_loopback or
is_link_local or is_reserved`), and the URL must be <= 2048 chars. Rationale in the
docstring: the stored endpoint becomes a URL this server will POST to on every
mention, so an unvalidated one is a stored SSRF primitive.

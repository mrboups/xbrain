### Task 1 — verify-phase11.sh (REVISION 2 — adds superadmin assertions 14-16)

**File(s):** `infrastructure/scripts/verify-phase11.sh`

**What:** Adopt the structure of `infrastructure/scripts/verify-phase7.sh` (helpers `run_psql`, `pass`, `fail`, `MEMAPI_HOST` env). 16 assertions (RESEARCH §Q10 has the body for 1-12 — paste lightly adapted; assertion 13 is from REVISION 1; assertions 14-16 are new in REVISION 2 to cover SC-8/9/10; key checks summarized):

1. Alembic version ≥ `0018_brain_events_view`.
2. `tasks.truth_level`, `tasks.deleted_at`, `tasks.deleted_by` columns present.
3. All 6 target tables have `deleted_at` column (loop).
4. `v_brain_events` view exists (`to_regclass`).
5. `v_brain_events` returns ≥ 1 distinct entity_type for team `default`.
6. `GET /v1/brain/events` returns 200 with auth + X-Team-Scope.
7. PATCH `/v1/brain/events/task/$TEST_TASK_ID_OWNED` by owner → 200; by non-owner → 403.
8. DELETE → 204; row absent from default list; present with `include_deleted=true`.
9. POST `.../restore` → 200; `deleted_at IS NULL`.
10. `GET /v1/tasks` API count == `SELECT COUNT(*) FROM tasks WHERE team_scope='default' AND deleted_at IS NULL` (regression filter active).
11. `docker inspect xbrain-brain-janitor --format='{{.State.Status}}'` → `running`. Sentinel file `/tmp/brain-janitor-alive` mtime within last 25h.
12. Migration preservation: `SELECT COUNT(*) FROM memory_items WHERE truth_level NOT IN ('EPHEMERAL','WORKING','VALIDATED','CANONICAL','PUBLIC')` → 0 (Success Criterion 6).
13. **Messages soft-delete regression (REVISION 1 — closes B-3 audit trail):** seed 2 messages in a fixture conversation (`TEST_CONVERSATION_ID`), soft-delete one via direct DB UPDATE, then assert API count == DB count == 1:
    ```bash
    API_COUNT=$(curl -s -H "Authorization: Bearer $TEST_XBT" -H "X-Team-Scope: default" \
      "$MEMAPI_HOST/v1/messages?conversation_id=$TEST_CONVERSATION_ID" | jq '.items | length')
    DB_COUNT=$(run_psql -tA "SELECT COUNT(*) FROM messages WHERE conversation_id='$TEST_CONVERSATION_ID' AND deleted_at IS NULL")
    if [ "$API_COUNT" = "$DB_COUNT" ] && [ "$API_COUNT" = "1" ]; then
      pass "13. GET /v1/messages excludes soft-deleted ($API_COUNT API == $DB_COUNT DB == expected 1)"
    else
      fail "13. messages list mismatch: API=$API_COUNT DB=$DB_COUNT expected=1"
    fi
    ```
    Discover endpoint path: `curl -s "$MEMAPI_HOST/openapi.json" | jq '.paths | keys[] | select(contains("messages"))'`.

14. **Superadmin overview endpoint (REVISION 2 — SC-8 + SC-10g):** GET `/v1/admin/brain/overview` with superadmin token returns ≥2 team entries; same call with a non-superadmin token returns 403.
    ```bash
    # 14a — superadmin can read overview, ≥2 teams
    OVERVIEW=$(curl -s -H "Authorization: Bearer $SUPERADMIN_XBT" "$MEMAPI_HOST/v1/admin/brain/overview")
    TEAM_COUNT=$(echo "$OVERVIEW" | jq 'length')
    if [ "$TEAM_COUNT" -ge 2 ]; then
      pass "14a. superadmin /v1/admin/brain/overview returns $TEAM_COUNT teams (≥2 expected)"
    else
      fail "14a. expected ≥2 teams in overview, got $TEAM_COUNT"
    fi
    # 14b — non-superadmin gets 403
    HTTP_403=$(curl -s -o /dev/null -w "%{http_code}" -H "Authorization: Bearer $TEST_XBT_MEMBER" \
      "$MEMAPI_HOST/v1/admin/brain/overview")
    if [ "$HTTP_403" = "403" ]; then
      pass "14b. non-superadmin gets 403 on /v1/admin/brain/overview"
    else
      fail "14b. expected 403, got $HTTP_403"
    fi
    ```

15. **Drill-down writes audit_log (REVISION 2 — SC-9 + SC-10h):** GET `/v1/admin/brain/events?team_slug=$TEST_DRILLDOWN_TEAM_SLUG` with superadmin token. Pre-count audit_log entries, call endpoint, post-count, verify N+1.
    ```bash
    # 15 — drill-down writes exactly 1 audit_log entry per call
    BEFORE=$(run_psql -tA "SELECT COUNT(*) FROM audit_log WHERE action='superadmin_brain_access' AND team_scope='$TEST_DRILLDOWN_TEAM_SLUG'")
    HTTP_200=$(curl -s -o /dev/null -w "%{http_code}" -H "Authorization: Bearer $SUPERADMIN_XBT" \
      "$MEMAPI_HOST/v1/admin/brain/events?team_slug=$TEST_DRILLDOWN_TEAM_SLUG&limit=5")
    AFTER=$(run_psql -tA "SELECT COUNT(*) FROM audit_log WHERE action='superadmin_brain_access' AND team_scope='$TEST_DRILLDOWN_TEAM_SLUG'")
    DELTA=$((AFTER - BEFORE))
    if [ "$HTTP_200" = "200" ] && [ "$DELTA" = "1" ]; then
      pass "15. drill-down 200 + audit_log incremented by 1 (delta=$DELTA)"
    else
      fail "15. drill-down http=$HTTP_200 audit_delta=$DELTA expected http=200 delta=1"
    fi
    ```

16. **ADMIN_USER_SUBS lockdown (REVISION 2 — SC-10i):** With `ADMIN_USER_SUBS=""` (env unset), ALL `/v1/admin/brain/*` endpoints return 403 — even for a previously-superadmin principal. This requires a memory-api restart with the env temporarily blanked. The verify script either:
    - **(preferred path)** runs the assertion against a test deployment with `ADMIN_USER_SUBS=""` pre-configured (operator sets `LOCKDOWN_TEST=1` env to enable this assertion), OR
    - **(fallback path)** skips assertion 16 with an explicit `SKIP: 16 (LOCKDOWN_TEST=1 not set)` marker, documenting in the script header that operator must manually verify by setting the env, restarting memory-api, and re-running the curl.

    ```bash
    if [ "${LOCKDOWN_TEST:-0}" = "1" ]; then
      # Test all 5 admin endpoints under lockdown
      ALL_403=1
      for ep in overview storage activity sources "events?team_slug=default"; do
        CODE=$(curl -s -o /dev/null -w "%{http_code}" -H "Authorization: Bearer $SUPERADMIN_XBT" \
          "$MEMAPI_HOST/v1/admin/brain/$ep")
        if [ "$CODE" != "403" ]; then
          ALL_403=0
          fail "16. expected 403 on /v1/admin/brain/$ep under lockdown, got $CODE"
          break
        fi
      done
      if [ "$ALL_403" = "1" ]; then
        pass "16. ADMIN_USER_SUBS lockdown — all 5 admin/brain endpoints return 403"
      fi
    else
      echo "SKIP: 16 (LOCKDOWN_TEST=1 not set — operator must verify manually)"
    fi
    ```

The script must emit `PASS: N / 16` at the end (or `PASS: N / 16 (M skipped)` if fixtures or lockdown test missing). Use existing `set -e` + trap pattern from verify-phase7.sh.

Test fixtures (sourced from `infrastructure/.env.test` — operator-provided): `TEST_TASK_ID_OWNED`, `TEST_TASK_ID_OTHER_USER`, `TEST_XBT`, `TEST_XBT_MEMBER`, `TEST_CONVERSATION_ID`, `SUPERADMIN_XBT` (token for a principal whose sub is in ADMIN_USER_SUBS), `TEST_DRILLDOWN_TEAM_SLUG` (any non-default team slug for drill-down testing). Document this in the script header.

**Why:** Single command to confirm Phase 11 health, including the superadmin scope addition. Success Criteria 7 + 10 demand this. Assertion 13 is the automated guard for B-3 (messages regression). Assertions 14-16 are the automated guards for the superadmin scope — without them, a future regression that drops `assert_is_superadmin` or the audit write would not trip the verify script.

## Section 4 — Risks + Mitigations

- **Risk: verify script fails because test fixtures missing.** Mitigation: document that `TEST_TASK_ID_OWNED`, `TEST_CONVERSATION_ID`, `SUPERADMIN_XBT`, `TEST_DRILLDOWN_TEAM_SLUG` etc. are required env vars; script gracefully skips those checks with `PASS: N (M skipped)`.
- **Risk: assertion 16 (lockdown) requires a memory-api restart with `ADMIN_USER_SUBS=""`.** Mitigation: gate it behind `LOCKDOWN_TEST=1` env; if not set, the script emits an explicit SKIP message and the operator verifies manually. The script header documents the manual procedure.
- **Risk: assertion 15 might fail if 11-10's executor changed the audit `team_scope` semantics.** Mitigation: the assertion queries by `team_scope=<TEST_DRILLDOWN_TEAM_SLUG>` which matches the documented invariant in 11-10 Task 4. If the audit row uses `target_team_slug` in payload only (not on the `team_scope` column), the assertion's WHERE clause adapts: `WHERE action='superadmin_brain_access' AND payload->>'target_team_slug'='<slug>'`. Document both forms in the script.
- **Risk: docs page diverges from actual UI behavior.** Mitigation: write docs AFTER 11-08, 11-10, 11-11 ship (this plan is wave 6, depends on all prior plans).
- **Risk: playwright-mcp not installed.** Mitigation: UAT is fully doable manually; playwright is optional capture. Document as optional in 11-UAT.md.
- **Risk: SUMMARY template ages out.** Mitigation: template stays minimal — operator fills in actual results.
- **Risk: docs/_sidebar.html naming convention differs from assumption.** Mitigation: Task 2 starts by reading `marketing-site/docs/` to find the actual sidebar file before editing.
- **Risk: messages endpoint path differs from `/v1/messages?conversation_id=`.** Mitigation: Task 1's assertion 13 includes a `curl openapi.json` discovery hint so the operator can adapt the URL before running.
- **Risk: UAT step 8 cannot proceed because there's only 1 team in the dev DB.** Mitigation: UAT script preamble instructs the operator to ensure ≥2 teams exist via `POST /v1/admin/teams` (existing endpoint) before running step 8.

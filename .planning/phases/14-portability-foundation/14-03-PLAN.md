<objective>
De-hardcode the infrastructure layer (PORT-01, Tier A + Tier B) so an operator points the whole
stack at their own domain via config alone: nginx vhosts become env-driven templates (official
nginx image envsubst), every `docker-compose.yml` `${VAR:-...grooveos.app}` fallback is neutralized,
the one unwrapped hardcode (`WEBUI_URL`) gets a `${...:-}` wrapper, `librechat.yaml`'s three brand
strings resolve from `${VAR}`, and Centrifugo's allowed-origins moves to an env var.

Purpose: PORT-01's "point at your own domain via config alone" is violated if the operator must
edit nginx/compose source. Regression safety (SC#2): every neutralized fallback keeps its env
override, so setting the vars back to prod values reproduces prod exactly.
Output: config-driven infra with neutral defaults and a boot-safe bare `docker compose up`
(except the two OAuth identity vars, which fail-fast by design — see Plan 14-01).
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| internet → nginx vhosts | server_name routing decides which upstream a request reaches |
| browser → LibreChat allowedDomains / Centrifugo allowed_origins | SSRF/CORS allow-lists gate cross-origin behavior |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-14-10 | Spoofing | nginx envsubst mangling nginx runtime vars ($host) if unfiltered | mitigate | `NGINX_ENVSUBST_FILTER=^XBRAIN_` limits substitution to XBRAIN_* only; nginx's own vars are never in env. |
| T-14-11 | Tampering | Both OAuth env fallbacks must be empty in BOTH services (memory-api + mcp-brain) or tokens minted for one resource are rejected by the other | mitigate | Task 2 sets `${OAUTH_ISSUER_URL:-}`/`${OAUTH_RESOURCE_URL:-}` empty in both env blocks together; acceptance greps for exactly 2 empty occurrences (14-RESEARCH.md Pitfall 3). |
| T-14-12 | Information Disclosure | LibreChat allowedDomains / Centrifugo origins defaulting to a foreign domain widening the CORS surface | accept | Neutral `localhost` default narrows, not widens; operator sets their real domain. RFC 8707 audience binding + shared-secret gates unchanged. |
</threat_model>

### Task 2 — Créer verify-phase5.sh (8 tests)

**What:** Créer le script `infrastructure/scripts/verify-phase5.sh` avec 8 tests numérotés (pattern identique à `verify-phase4.sh`). Chaque test est autonome, retourne PASS ou FAIL avec un message explicite.

**Files:**
- `infrastructure/scripts/verify-phase5.sh`

**How:**

Copier la structure de `verify-phase4.sh` (header, pattern de test `PASS`/`FAIL`, compteur, exit code final). Les 8 tests à implémenter :

```bash
#!/bin/bash
# verify-phase5.sh — Phase 5 Plateforme Projets Équipe verification
# Usage: bash infrastructure/scripts/verify-phase5.sh
# Run from repo root on the VM where docker compose is running.

set -euo pipefail
PASS=0; FAIL=0

run_test() {
    local name="$1"; local cmd="$2"
    if eval "$cmd" &>/dev/null; then
        echo "PASS [$((PASS+1))] $name"; PASS=$((PASS+1))
    else
        echo "FAIL [$((FAIL+1))] $name"; FAIL=$((FAIL+1))
    fi
}
```

**Test 1 — graphiti-service healthcheck (port 8300) :**
```bash
run_test "graphiti-service health (port 8300)" \
    "wget -qO- http://localhost:8300/v1/healthz 2>/dev/null | grep -q 'ok'"
```

**Test 2 — graphiti-service POST /v1/ingest → 202 :**
```bash
run_test "graphiti-service POST /v1/ingest → 202 Accepted" \
    "curl -sf -o /dev/null -w '%{http_code}' -X POST http://localhost:8300/v1/ingest \
        -H 'Content-Type: application/json' \
        -d '{\"content\":\"test Phase 5 verify\",\"group_id\":\"acme\"}' | grep -q '202'"
```

**Test 3 — GitHub OAuth dans librechat.yaml :**
```bash
run_test "librechat.yaml a 'github' dans socialLogins" \
    "grep -q 'github' infrastructure/librechat/librechat.yaml"
```

**Test 4 — Migration 0007 : colonne github_username dans users :**
```bash
# Utilise docker compose exec postgres pour vérifier la colonne
run_test "table users a la colonne github_username (migration 0007)" \
    "docker compose -f infrastructure/docker-compose.yml exec -T postgres \
        psql -U \"\${POSTGRES_USER}\" -d \"\${POSTGRES_DB}\" -tAc \
        \"SELECT column_name FROM information_schema.columns WHERE table_name='users' AND column_name='github_username';\" \
        | grep -q github_username"
```

Note : utiliser `-T` (no pseudo-TTY) pour éviter les problèmes d'output dans un script non-interactif. Exporter `POSTGRES_USER` et `POSTGRES_DB` depuis le `.env` avant d'exécuter le script, ou les hardcoder si connus.

**Test 5 — brain.yaml schema (parsing de l'exemple) :**
```bash
run_test "brain.yaml example est parseable (docs/brain-yaml-schema.md)" \
    "python3 -c \"
import yaml, re
content = open('docs/brain-yaml-schema.md').read()
# Extraire le premier bloc yaml du doc
match = re.search(r'\`\`\`yaml(.*?)\`\`\`', content, re.DOTALL)
if not match: exit(1)
d = yaml.safe_load(match.group(1))
assert 'name' in d and 'slug' in d and 'team_scope' in d
\""
```

**Test 6 — Chrome extension manifest.json valide MV3 :**
```bash
run_test "chrome-extension/manifest.json est Manifest V3 valide" \
    "python3 -c \"
import json
d = json.load(open('chrome-extension/manifest.json'))
assert d['manifest_version'] == 3
assert 'background' in d
assert 'identity' in d.get('permissions', [])
\""
```

**Test 7 — projects.dejavu.cat Firebase config existe :**
```bash
run_test "projects-dashboard/firebase.json existe et est valide JSON" \
    "python3 -c \"import json; d=json.load(open('projects-dashboard/firebase.json')); assert 'hosting' in d\""
```

Note : on ne peut pas tester `projects.dejavu.cat` respond depuis la VM sans accès réseau externe. On vérifie la config locale.

**Test 8 — memory-api CORS headers incluent chrome-extension :**
```bash
run_test "memory-api CORS: Access-Control-Allow-Origin inclut chrome-extension" \
    "curl -sI -X OPTIONS http://localhost:8000/v1/healthz \
        -H 'Origin: chrome-extension://testextension' \
        -H 'Access-Control-Request-Method: GET' \
        | grep -i 'access-control-allow-origin'"
```

Note : si `chrome-extension://*` n'est pas supporté comme wildcard dans certaines versions de FastAPI CORS, le test vérifie juste la présence du header. Si absent, vérifier la config CORSMiddleware en plan 05-04 Task 3.

**Fin du script :**
```bash
echo ""
echo "=== Phase 5 Verification ==="
echo "PASS: $PASS / $((PASS+FAIL))"
echo "FAIL: $FAIL / $((PASS+FAIL))"
[ $FAIL -eq 0 ] && echo "ALL TESTS PASSED" && exit 0 || echo "SOME TESTS FAILED" && exit 1
```

**Test du script :**
```bash

bash -n infrastructure/scripts/verify-phase5.sh && echo "Syntax OK"
```

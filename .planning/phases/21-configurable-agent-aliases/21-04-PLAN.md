| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|

Test case 5 proves escaping. |
| T-21-04-02 | Spoofing | @claude summoned client-side | mitigate | buildMentionRegex filters "claude" case-insensitively AND the server never stores it; Test case 3 asserts @claude → null. |

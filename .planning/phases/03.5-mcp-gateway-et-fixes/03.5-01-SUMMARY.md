# Phase 3.5 Plan 01 Summary — mcp-gateway : réécriture call_tool() via MCP Python SDK

## Ce qui a été fait

Réécriture complète de `call_tool()` dans `apps/mcp-gateway/app/main.py` pour utiliser le SDK officiel MCP Python (`mcp>=1.0.0`) comme client stateful, en remplacement du proxy HTTP brut qui retournait 400 Bad Request.

### Changements appliqués

**`apps/mcp-gateway/pyproject.toml`**
- Ajout de `"mcp>=1.0.0"` dans les dépendances

**`apps/mcp-gateway/app/main.py`**
- Retrait de `import httpx` (plus utilisé après réécriture)
- Retrait de `import json as _json` (idem)
- Retrait de `MCP_PROTOCOL_VERSION` (constante obsolète avec le SDK)
- Ajout des imports : `from mcp import ClientSession` + `from mcp.client.streamable_http import streamablehttp_client`
- Réécriture de `call_tool()` avec le pattern stateful :
  `streamablehttp_client(url, headers=...)` → `ClientSession(read, write)` → `session.initialize()` → `session.call_tool(name, args)`
- Retrait des variables `_rpc_method` et `_body_json` (plus utilisées)
- Conservation intacte : auth, registry, /tools GET, /admin/register, audit

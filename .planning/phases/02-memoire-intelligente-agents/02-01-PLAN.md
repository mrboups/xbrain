  <action>
Créer `apps/spike-mem0/spike.py` qui :

1. **Setup local backends** (assume Postgres+Qdrant déjà up via docker run) :
   - mem0 client : `Memory.from_config({"vector_store": {"provider": "qdrant", "config": {"host": "localhost"}}})`
   - **NOTE clé** : encoder `team_scope` comme `user_id = f"team:{team_scope}"` (workaround mem0 = pas de team_id natif)

2. **Test 1 — Team isolation** :
   - Ingest les 100 facts (loop, ~30 par team)
   - Pour chaque team T : `mem0.search(query="any", user_id=f"team:{T}")`
   - Compter combien de résultats appartiennent à une AUTRE team (leak count)
   - Pass si **leak == 0**

3. **Test 2 — Versioning** :
   - Pick 1 fact, `add()` initial
   - `update()` le fact 3 fois (different content each time)
   - `get_history(fact_id)` : récupérer toutes les versions
   - Pass si on récupère ≥3 versions avec timestamps différents

4. **Test 3 — Truth-level glue effort** :
   - **Mesure** : count lines of "glue code" qu'on devrait écrire pour overlayer le state machine truth-level (`EPHEMERAL → ... → PUBLIC`) sur mem0
   - Approche pragmatique : implémenter `promote_truth_level(fact_id, from, to, approver_id)` qui :
     - Read le fact via mem0
     - Validate state transition allowed
     - Update fact metadata avec new truth_level
     - Insert audit row dans Postgres `promotions` table (qu'on simule)
   - Compter lines de code requises (sans imports/empty lines)
   - Pass si ≤ 100 lignes de glue (raisonnable)

5. **Test 4 — Latency** :
   - 1000 search queries (round-robin sur les 3 teams, query random words)
   - Mesurer P50, P95, P99 latency en ms
   - Pass si **P95 < 500ms** (perf budget memory-api Phase 2)

6. **Output** : write `spike-results.json` :
```json
{
  "test_1_team_isolation": {"leak_count": 0, "pass": true},
  "test_2_versioning": {"versions_retrieved": 3, "pass": true},
  "test_3_glue_lines": {"lines": 78, "pass": true},
  "test_4_latency_ms": {"p50": 120, "p95": 340, "p99": 580, "pass": true},
  "all_pass": true,
  "recommendation": "GO mem0 (or NO-GO mem0 with reasons)"
}
```

Le script DOIT être idempotent : delete tous les facts mem0 du test au début, ré-ingest, ré-test.

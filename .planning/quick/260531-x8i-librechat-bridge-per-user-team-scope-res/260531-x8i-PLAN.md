# Quick Task 260531-x8i — Per-user team_scope resolution in librechat-bridge

## Problem (root cause, verified live on VM 2026-05-31)

`apps/librechat-bridge/app/mongo_watcher.py::resolve_team_scope()` is a never-finished
Phase-1 stub that always returns `settings.BRIDGE_DEFAULT_TEAM_SCOPE` ("default"),
ignoring the user. Both LibreChat passive recall (`message_enricher.enrich_turn`) and
brain ingest (`_maybe_ingest_to_brain`) therefore operate under `team_scope="default"`,
while real team facts live under the user's actual team slug (e.g. `your-team`). Result:
LibreChat never recalls team facts and writes new messages into the wrong brain. The
Chrome-extension/team-chat path resolves the real team correctly via `/v1/me`, so the two
halves of the differentiator never meet.

## Tasks

### Task 1 — memory-api: internal resolve-team-scope endpoint
- **files:** `apps/memory-api/app/routes/internal.py` (new), `apps/memory-api/app/main.py` (wire router), `apps/memory-api/tests/test_internal_resolve_team_scope.py` (new)
- **action:**
  - New router file `routes/internal.py` exposing `GET /v1/internal/resolve-team-scope?sub=<str>`.
  - Auth: `Depends(get_current_principal)` ONLY (accept any authenticated principal incl. `kind=="bridge"`). Do NOT use `get_team_scope` (team unknown at call time).
  - Resolution (reuse existing repos — do not duplicate SQL):
    1. `user = SELECT User WHERE source_user_id == sub` (exact, via a small select or `repos.users`).
    2. if None and `sub.startswith("email:")`: `user = get_user_by_email(session, sub[len("email:"):])`.
    3. if None and `"@" in sub`: `user = get_user_by_email(session, sub)`.
    4. if user: `user = await follow_merge_pointer(session, user)`.
    5. `team = await get_first_team_for_user(session, user_id=user.id)` if user else None.
    6. return `{"team_scope": team.slug if team else None, "user_id": str(user.id) if user else None}`.
  - Never 500 on unknown user — return `{"team_scope": null, "user_id": null}`.
  - Wire router into `app/main.py` exactly like the other routers (same prefix convention — the route path already includes `/v1/...` OR the include_router prefix supplies `/v1`; match whatever the existing routers do so the final path is `GET /v1/internal/resolve-team-scope`).
- **verify:** `pytest apps/memory-api/tests/test_internal_resolve_team_scope.py` (if a local env exists); else import-check the module compiles. Endpoint returns the slug for an email-style sub that maps to a team member; returns `{"team_scope": null}` for an unknown sub.
- **done:** route registered, resolves identity->slug, null-safe, test added.

### Task 2 — librechat-bridge: implement resolve_team_scope with cache + fallback
- **files:** `apps/librechat-bridge/app/memory_api_client.py`, `apps/librechat-bridge/app/mongo_watcher.py`, `apps/librechat-bridge/tests/test_resolve_team_scope.py` (new)
- **action:**
  - Add `MemoryApiClient.resolve_team_scope(self, *, sub: str) -> str | None`:
    - `GET {base}/v1/internal/resolve-team-scope?sub=<sub>` with a bridge JWT
      `make_bridge_jwt(sub=sub, team_scope=settings.BRIDGE_DEFAULT_TEAM_SCOPE)`.
    - Return response JSON `"team_scope"` (may be None). On `httpx.HTTPError` return None.
    - Follow the existing `@retry(... retry_if_exception_type(httpx.HTTPError) ...)` decorator
      pattern used by the other client methods.
  - Replace the body of `mongo_watcher.resolve_team_scope(client, user_sub)`:
    - Keep the EXACT signature `async def resolve_team_scope(client: MemoryApiClient, user_sub: str) -> str`.
    - Module-level in-memory TTL cache `dict[str, tuple[str, float]]` (sub -> (team_scope, expiry_epoch)), TTL ~300s, using `time.time()` (NOT datetime). On hit & not expired -> return cached value.
    - On miss: `scope = await client.resolve_team_scope(sub=user_sub)`; if `scope` is a non-empty string -> cache + return it; else return `settings.BRIDGE_DEFAULT_TEAM_SCOPE` WITHOUT caching the fallback (so a later signup self-heals on the next message).
    - Wrap in try/except so it NEVER raises — any exception returns `settings.BRIDGE_DEFAULT_TEAM_SCOPE`.
    - Add `import time` if not present.
- **verify:** `pytest apps/librechat-bridge/tests/test_resolve_team_scope.py` (if local env); test: returns slug when client returns it; falls back to default when client returns None; second call within TTL served from cache (client called once — assert via mock call_count).
- **done:** stub replaced, cache + fallback + fail-soft, client method added, test added.

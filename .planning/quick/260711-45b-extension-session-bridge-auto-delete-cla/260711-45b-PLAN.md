<objective>
Auto-delete each bridged claude.ai conversation immediately after its completion
stream ends, so the disposable containers created per message stop polluting the
user's real claude.ai chat history.

This is "piste 1" — auto-delete only. The bridge is stateless on claude.ai's side
(`openaiToClaudeAi()` flattens the ENTIRE history into one `prompt` and always sends
`parent_message_uuid = nil`), so the server-side conversation is never read back for
context. Nothing references `convUuid` after the `end` frame → deleting it right away
is safe.

Purpose: keep the user's claude.ai chat list clean without touching the response path.
Output: DELETE endpoint + best-effort cleanup in `claude_ai_client.js`, a node test
proving ordering + best-effort behavior, updated capture doc, and a deferred-items note.
</objective>

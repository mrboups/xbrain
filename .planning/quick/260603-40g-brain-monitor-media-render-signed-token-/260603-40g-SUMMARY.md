## New endpoint

```
GET /v1/media/{item_id}/img?t=<signed-token>
```

- No Bearer header required — usable from `<img src>` and `<a href>`.
- `t` is an HS256 JWT signed with `BRIDGE_SHARED_SECRET`.
- Claims: `{"scope":"media","item_id":"<uuid>","team_scope":"<slug>","iat":<n>,"exp":<n+3600>}`.
- Returns the raw object from MinIO with `Content-Type: <mime>`, `Cache-Control: private, max-age=300`.
- Existing `GET /v1/media/{item_id}/raw` (Bearer-authed) is unchanged.

---

## Token shape

```json
{
  "scope": "media",
  "item_id": "<uuid>",
  "team_scope": "<team-slug>",
  "iat": 1748000000,
  "exp": 1748003600
}
```

Signed HS256, secret = `BRIDGE_SHARED_SECRET`. TTL = 3600s (1 hour).  
The MinIO object key is **never** forwarded to the client — only `mime`, `size`, `filename`, and the token URL.

Add xbrain to the iPhone share sheet

iOS does not let a web app join the share sheet. Apple's Shortcuts app can: this is a one-time setup that adds "Save to xbrain" to the sheet, so sharing a conversation from ChatGPT sends it straight to your team.

  1. Start with the credential the shortcut will carry. It is an import token, not your account token: it can do one thing - import into this team - and cannot read the chat, the brain or your account. Shown once. Copy it now. If you leave without it, press the button again for a new one - the one you lost keeps working until you revoke it.
  2. Open Shortcuts, tap +, then the (i) button and turn on Show in Share Sheet.
  3. Under Receive, choose Text and URLs from the share sheet.
  4. Add the action Get Contents of URL and expand it with the arrow.
  5. Set the URL to:
  6. Set Method to POST.
  7. Add three Headers - the first one takes the token from step 1: The team is the one selected above. Change that value to point the shortcut at another team.
  8. Set Request Body to File, and drop the Shortcut Input variable into it. The shared conversation IS the body - there is no JSON to build.
  9. Name it Save to xbrain. Sharing from ChatGPT now offers it.

One thing it cannot do: a bare share link. The server will not open a link on your behalf, so share the conversation's text - copy it in ChatGPT and share that.

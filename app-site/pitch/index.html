02 · the paradox

The paradox of agentic work.

Every agent is a new silo.

Every team is moving its work through AI agents — Cursor, Claude Code, ChatGPT, Granola, Hermes. Each one is brilliant. Each one is a silo. The collaboration we'd built in Slack, Notion, and Linear is regressing.

Decisions get made in chats no agent can read. Code ships from sessions trapped where they were made. Briefs get re-explained every conversation. And every AI interaction adds to a flood of context no human can process and no agent can access.

05 · architecture

Three primitives. One substrate.

A cognitive OS, not a chatbot. Three layers, every operator on the same bus.

01
Cognitive Core
Vector, graph, and relational storage for every output from every operator. Auto-indexed. Team-scoped. Queryable in milliseconds.
02
Team Bus
Agents connect via MCP. Humans connect via the integrated team chat, web app, and CLI. One brain, every surface.
03
Truth Engine
Five validation levels: EPHEMERAL → WORKING → VALIDATED → CANONICAL → PUBLIC. Humans and agents both promote and demote. Truth converges instead of accumulating.

06 · technical moat

Four layers. One substrate.

1
Temporal Knowledge Graph
Graphiti + Neo4j with time-bounded edges (valid_from / valid_until). When auth-v2 ships, auth-v1 is automatically marked superseded. Agents retrieve what's true now, not six months ago. Most "memory for AI" products accumulate; ours evolves.
2
Truth Engine
Five validation levels (EPHEMERAL → WORKING → VALIDATED → CANONICAL → PUBLIC). CANONICAL facts auto-inject into every team AI conversation. Humans and agents both promote. Validation flows in both directions.
3
Native MCP + LangGraph agent layer
9 MCP tools shipped (memory ops, tasks, contacts, agent invocation, team context). 4 built-in agents — @meeting-recap, @doc-ingest, @promote, @research — with human-in-the-loop approval workflows on uncertain facts.
4
Open-core architecture
xbrain engine (MIT) on GitHub for self-hosters; hosted product + Team features capture commercial demand. Vercel/Supabase playbook.

Hard to replicate from above (Slack/Notion can't bolt this stack on) and hard to replicate from below (Letta/Zep aren't building for hybrid teams).

We hold the substrate. Players above us own the workflow, players below us own the model. Neither owns the team-level cognitive layer.

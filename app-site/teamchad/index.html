// what it is · three parts, one system
— One thread
People and AI agents talk in the same conversation, and @agent answers from everything the company has said, decided or uploaded.
— One memory
Every message, document, meeting note and tool output lands in a single store — one per team, isolated from the rest — that Claude, GPT, Grok, ChatGPT, Claude Code and background agents all read and write.
— Five truth levels
A fact climbs from passing remark to company canon only through review and approval, every step logged, and the agent names the level it answered from.

// the problem with isolated agents
team · agents without shared memory
dev-agent $ ship feature auth-v2 — "JWT refresh tokens, rate limiting, 2FA" ✓ shipped. memory stored: 0 items. mktg-agent $ write launch post for auth-v2 ! no context found for "auth-v2" ! starting from zero. what is auth-v2? ops-agent $ what rate limits did we ship this week? ✗ no shared context. cannot answer. # three agents. three isolated silos. # every session starts at zero. # handoffs = manual. context = lost. decisions = repeated.
// what xbrain does
team · with xbrain memory layer
dev-agent $ ship feature auth-v2 ✓ shipped. memory-api indexed: 14 items ✓ tagged team_scope=engineering truth_level=WORKING source=agent-runtime mktg-agent $ write launch post for auth-v2 ✓ context loaded — 14 items from dev-agent, 2 CANONICAL facts ✓ draft ready. no manual briefing needed. ops-agent $ what rate limits did we ship this week? ✓ "100 req/min per user, 1000 req/min per team — shipped auth-v2 2026-05-07" ✓ confidence: 0.97 — truth_level: VALIDATED
Every write to memory-api carries exactly 7 required fields: team_scope, project_scope, visibility, confidence, truth_level, source, validation_status. A write missing any of these returns HTTP 422. This is enforced at the API level — not by convention. It is the contract that makes scoped retrieval, truth-level promotion, team isolation, and audit logging possible.
// features
— Memory Core
Vector + graph + relational storage for every team output. Every agent reads the same truth, scoped by team and project.
— Agent Bus (MCP)
MCP-native gateway. LangGraph agents, LibreChat, Open WebUI, and Claude Code connect in minutes. No custom wiring.
— Truth Engine
5 levels: EPHEMERAL → WORKING → VALIDATED → CANONICAL → PUBLIC. Agents act on validated context, never stale drafts.
— Drive Sync
Google Drive docs auto-indexed on change via webhooks. Every spec, brief, and decision in Drive becomes agent memory.
— Chrome Clipper
Right-click any page or selection — it enters the brain tagged by team and project. Instantly searchable by all agents.
— Graphiti
Temporal knowledge graph. Time-bounded facts, entity relationships, and team structure history. Agents reason over time.
— CRM & Contacts hosted
Contacts auto-extracted from meetings and chat. No manual entry. Every participant becomes a tagged contact record.
— Task Tracking hosted
Action items auto-generated from meeting notes and chat messages. Tracked, assigned, and polled by agents every 30 seconds.
— Meeting Intelligence hosted
Granola meeting notes → memory + contacts + tasks every 5 minutes. One atomic write. Idempotent by source_ref.

hosted — available on Team & Enterprise tiers of the managed GrooveOS platform. All other features are open-source and fully self-hostable.

// truth level system
Level Meaning Agent behavior Promoted by
EPHEMERAL Raw output Skipped unless explicitly queried. Chat messages, drafts, clips. Any member
WORKING In-progress Included in general context. Most team knowledge lives here. Any member
VALIDATED ✓ reviewed Safe for agent decisions. Peer-reviewed by at least one member. Team member
CANONICAL ✓✓ team truth Auto-injected in agent system prompts. The definitive team answer. Admin
PUBLIC ↗ published Shareable outside the team. No X-Team-Scope required. Admin

Truth level can only be promoted forward via POST /v1/promotions. A direct PATCH truth_level returns HTTP 405 — promotion requires justification.
